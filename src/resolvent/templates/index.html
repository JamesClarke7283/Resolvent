A QUICK GUIDE
A notation for every thought.
Use Visual to write with the maths keyboard, LaTeX for notation such as \frac{x^2}{2}, or Python for sin(x) * exp(x).
Expressions
Python requires explicit multiplication: 2*x. Use ** for powers, Eq(x**2, 4) for equations, and Matrix([[1,2],[3,4]]) for matrices. Decimal inputs are exact rationals.
Operations
Choose an operation, then set variables and parameters. Parameters always use Python maths syntax, even with LaTeX input. Load an example to see the expected format.
Worksheets
Successful calculations become worksheet cells. Save them locally, export JSON, or open Saved worksheets to import. Reopen any history item to inspect its inputs and result.
Boundaries
Supported by SymPy; some problems have no known closed form. Unevaluated results and conditions are shown explicitly. Sampled plots can miss discontinuities. The engine is not a general Python interpreter.
Also at home in your terminal.uv run resolvent calc integrate 'x**2' --param 'bounds=[0,1]'uv run resolvent mcp
